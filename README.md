# 📈 デイトレスクリーナー

日本株のデイトレード・短期スイング向け銘柄スクリーニングツール。  
ボラティリティ・売買代金・材料・PTS情報を一画面で確認できます。

---

## 🖥️ アクセス方法

| バージョン | URL / 起動方法 |
|---|---|
| **Webスマホ版** | https://jpn-x.github.io/kabu-screener/ |
| **WebPC版** | https://jpn-x.github.io/kabu-screener/desktop.html |
| **PCデスクトップソフト** | `dist/デイトレスクリーナー.exe` をダブルクリック |

> **iPhoneホーム画面追加**: Safari で開いて「ホーム画面に追加」→ アプリとして起動できます

---

## 🔧 主な機能

### スクリーニング
- **データソース選択**（複数選択可）: 売買代金 / 出来高 / 値上がり率 / 値下がり率 / ストップ高 / ストップ安
- **市場フィルター**: 全市場 / プライム / スタンダード / グロース
- **フィルター条件** (スライダーで調整):
  - 日中ボラ(%) ≥
  - 売買代金(億) ≥
  - 前日比 絶対値(%) ≥

### ボラティリティ計算期間
| 期間 | 計算方法 |
|---|---|
| 当日 | 当日の高値〜安値 ÷ 前日終値 |
| 3日 | 直近3日間の高値〜安値 ÷ 3日前終値 |
| 5日 | 直近5日間の高値〜安値 ÷ 5日前終値 |
| 20日（1ヶ月）| 直近20日間の高値〜安値 ÷ 20日前終値 |

> S高連続のような急騰銘柄は長期ボラが大きくなります

## 📊 表示項目

| 列名 | 内容 |
|---|---|
| コード | 銘柄コード（クリックで株探ニュースページ） |

## 🔴 PTS（夜間取引）ランキング

データソースボタン下の **🔴 PTS上昇** / **🔵 PTS下落** ボタンで確認できます。

- 株探モバイル版から上昇・下落各 **最大100件（5ページ分）** を取得
- 表示項目: PTS変化率 / PTS価格 / 通常終値 / 材料
- 「⬆ TOPに戻る」または「📈 デイトレスクリーナー」クリックで通常モードへ戻る

---

## 📰 材料表示

ソース優先順位:
1. **[IR/本日] [IR/前日]** — TDnet（東京証券取引所・適時開示）※最も信頼性が高い
2. **[みんかぶ]** — みんかぶニュース
3. **[ニュース]** — Google News RSS
4. **[株探]** — 株探ニュース

> **材料クリック** → ソースページを開く  
> **📋 アイコン** → ホバーで全IR一覧をツールチップ表示（TDnet取得分）

## 💡 使い方のコツ

### デイトレ銘柄を探す（基本設定）
```
データソース: 売買代金 + 値上がり率 + 値下がり率
日中ボラ: 5.0% ≥
売買代金: 2.5億 ≥
前日比: 5.0% ≥
```

### テーマ株・仕手株を探す
```
データソース: 値上がり率 + ストップ高
ボラ期間: 3日 or 5日（連騰している銘柄を捕捉）
日中ボラ: 10% ≥
```

### 翌日の仕込み候補（PTS活用）
```
🔴 PTS上昇 ボタン → 当日引け後に急騰している銘柄を確認
材料を確認して翌朝の値動きを予測
```

## 🗂️ データソース

| データ | ソース |
|---|---|

| ランキング（売買代金・値上がり等） | 株探（kabutan.jp） |
| PTSランキング | 株探モバイル（s.kabutan.jp） |
| 適時開示（IR） | TDnet（東証適時開示閲覧サービス） |
| ニュース | みんかぶ / Google News RSS |

## 📱 スマホ版の使い方

1. Safariで `https://jpn-x.github.io/kabu-screener/` を開く
2. 「ホーム画面に追加」でアプリとして保存
3. **フィルター条件▼** をタップで条件展開
4. **🔴 PTS上昇 / 🔵 PTS下落** でPTSランキング確認
5. 銘柄カードタップで株探ニュースページへ
